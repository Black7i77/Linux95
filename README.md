# Linux95

**Linux95** is a Debian 13 (Trixie) based live Linux distribution built around a lightweight classic desktop inspired by the mid-1990s PC era.

It uses **IceWM**, PCManFM, custom Linux95 GTK styling, a dedicated Linux95 desktop session, and the **Calamares graphical installer**.

> Linux95 is an independent open-source project. It is not affiliated with or endorsed by Microsoft.

---

## Linux95 v3.0

Current base:

- Debian GNU/Linux 13 (Trixie)
- amd64 / x86_64
- systemd
- IceWM
- PCManFM
- GTK 2 / GTK 3 Linux95 theme
- Custom Linux95 desktop session
- Linux95 wallpaper and desktop configuration
- Calamares graphical installer
- GRUB BIOS support
- GRUB UEFI support
- Live USB boot support

---

## Features

Linux95 includes:

- Classic lightweight desktop
- IceWM window manager
- Linux95 custom theme
- File Manager desktop shortcut
- Linux95 Terminal shortcut
- System Info shortcut
- Install Linux95 desktop launcher
- Live mode before installation
- Debian package management with APT
- Calamares installation environment
- BIOS and UEFI bootloader packages
- Custom Linux95 session configuration

The project is designed to remain lightweight enough to run on older PCs while still using a modern Debian base.
